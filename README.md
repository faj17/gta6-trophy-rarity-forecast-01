Forecasts each Grand Theft Auto VI trophy's earn rate on Exophase one week after launch, as five quantiles (5%, 25%, 50%, 75%, 95%) per trophy. It extrapolates tracked players and trophy earners separately — players dilute rates when Exophase refreshes in a flood of new players, earners grow as players reach each trophy — and falls back to a launch-dilution prior when the history is still flat.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
